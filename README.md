# Test technique Fluxcore : Le Fournil de Léa

Une petite vitrine Next.js (Next 16, React 19, Tailwind 4, TypeScript) pour une boulangerie fictive. L'interface est déjà faite : tu ne touches à aucun choix visuel, seulement au code.

## Le but

Voir comment tu travailles sur du vrai code avec une IA, sur deux points :

- **Ton efficacité** : ce que tu produis, et en combien de temps (d'où le chronomètre).
- **Ton esprit critique** : ce que tu repères sans qu'on te le montre, ce que tu vérifies avant de livrer, et ce que tu signales au lieu de le deviner.

Il ne s'agit pas de tout finir à tout prix : un rendu honnête sur ce qui est fait et ce qui reste vaut mieux qu'un rendu qui a l'air complet.

## Les règles

- **Durée maximale : 2 heures.** Si tu arrives à 2 h avec une tâche inachevée, tu t'arrêtes et tu le dis dans `RENDU.md`. Un travail inachevé mais honnête vaut mieux qu'un dépassement.
- **Tu te chronomètres toi-même.** Note l'heure de début et de fin de chaque tâche dans `RENDU.md`, pauses comprises si tu en fais.
- **L'IA est autorisée**, et même conseillée : c'est comme ça qu'on travaille chez Fluxcore. On regarde ce que tu en fais, pas si tu l'utilises.
- **Aucune liste de défauts ne t'est fournie.** Ce que tu trouves, tu le trouves.

## Lancer le projet

```bash
npm install
npm run dev
```

Le site tourne sur http://localhost:3000. `npm run build` doit passer sans erreur à la fin.

## Les trois tâches

Elles sont décrites dans [`BRIEF.md`](BRIEF.md). Fais-les dans l'ordre.

## Le rendu

1. Ton code (dépôt Git privé ou archive zip, sans `node_modules`).
2. Le fichier [`RENDU.md`](RENDU.md) rempli : tes temps, ce que l'IA a raté, tes décisions.

Envoie le tout à contact@fluxcoregroup.com.
